# Online Mouse Test

A quick browser-based tool for checking whether your mouse buttons and scroll wheel are working correctly.

## What you can test

- Left click
- Right click
- Middle click
- Back and forward buttons
- Scroll up
- Scroll down

If you want to check whether your mouse input is registering correctly, try the free [online mouse test](https://www.keyboardtest.org/mouse-test.html).

No installation is required — the test runs directly in your browser.

## Useful for

- Testing a new mouse
- Checking a used or refurbished mouse
- Troubleshooting button problems
- Verifying scroll-wheel input
- Quickly checking mouse controls before gaming or work

For more keyboard and input testing tools, visit [KeyboardTest.org](https://www.keyboardtest.org/).
